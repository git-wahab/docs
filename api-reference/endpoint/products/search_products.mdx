## Search Products

`GET /api/v1/products/search`

Search products by term and return paginated results.

### Query Parameters

| Parameter | Type | Required | Default | Description |
|---|---|---|---|---|
| `term` | string | ✅ | — | Search term to find products (minimum 2 characters) |
| `page` | integer | — | 1 | Page number for pagination |
| `per_page` | integer | — | 15 | Number of items per page |

### Responses

| Status | Description |
|---|---|
| `200 OK` | Successful operation |
| `401 Unauthorized` | Missing or invalid authentication token |
| `403 Forbidden` | Access denied |
| `422 Unprocessable Entity` | Validation error (e.g. missing or too-short term) |
