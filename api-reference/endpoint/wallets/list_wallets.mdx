## List Wallets

`GET /api/v1/wallets`

Returns all wallets belonging to the authenticated user.

### Responses

| Status | Description |
|---|---|
| `200 OK` | Successful operation |
| `401 Unauthorized` | Missing or invalid authentication token |
| `403 Forbidden` | Access denied |

### 200 — Wallet List
